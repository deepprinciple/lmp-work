**********************************************************************************

       Z-Matrices for Common Organic Molecules, Ions, and Complexes   

**********************************************************************************

 Notes:

 The directory above OPLS2020 has z-matrices with OPLS/2020 atom type assignments.
 The principal changes are for alkane carbons. Compare with the corresponding files 
 here that have traditional OPLS-AA atom types.

 For UNIX/Linux scripts for many standard jobs, see ~/boss/scripts,               
 or for Windows see %BOSSdir%\scripts.

 E.g., to perform a gas-phase optimization for any of the Z-matrices -
 use the xOPT script -
 xOPT moleculename
 Output is in out, sum, and plt.pdb
 To also obtain vibrational frequencies, use the xFREQ script.
 For more information, see the optimize test job.

 To perform a gas-phase Monte Carlo simulation at 25C for any of the Z-matrices,
 use the xMCGAS script -
 xMCGAS moleculename
 For more information, see the MCgas test job.

 To perform dihedral driving, see the dihdrive test job.        
 
 See the zzIons subdirectory for ions.

 See the zzArenes subdirectory for polycyclic conjugated hydrocarbons.

 Most files here use OPLS-AA charges. To obtain 1.14*CM1A charges, use        
 xAM1SP molecule
 The output Z-matrix is in sum  with the CM1A charges appended.
 For mono cations and anions use xAM1SP+ and xAM1SP-
 For repetitive charge calculation and optimization, use
 xZCM1A molecule
 
 The treatment of variable and additional bond angles and dihedral angles
 has been automated in BOSS versions >= 4.0. This allows for much simplified
 Z-matrix files. Please compare butane.old and butane.z. Some of the older Z-matrix
 files have not been converted to the new format, but they could be. The old
 format is still operable and allows for detailed control.

 These Z-matrix files have been accumulated over several years. Since there have
 been some changes and additions of force-field parameters during this time, the
 total energies that are on line one of the .z files are not necessarily current.
 Reoptimize (xOPT moleculename) to obtain the correct energy and structure; the
 new .z file is written to the file sum. Then cp sum moleculename.z (copy sum
 moleculename.z).

 The subdirectory zzConformers contains conformational results for many molecules;
 please see the README file in that directory.
